# 2. コネクター（MCP）をつなぐ

Web 版の Whiteboard Animation Maker を、Claude・Codex から操作できるようにします。

---

## ステップ 0：アプリ側で URL を出す（共通）

1. ブラウザで https://whiteboard-animation-maker.pages.dev/app/ を開く
   （古い画面が出たら、画面下の「再読み込み」を押すか、開き直す）
2. 歯車のメニュー →「AI 連携（MCP）」を開く
3. 「AI からの接続を受け付ける」をオンにする
   - 「受け付け中」と出れば準備できています
4. 「エンドポイントの URL」をコピーする
   - `https://whiteboard-mcp-relay.goonruntongue.workers.dev/mcp/〜` の形です
   - **この URL には合言葉が入っています。人に見せないでください**
   - 以下の `<URL>` は、このコピーした URL に置き換えてください

> **大事：** AI はこのブラウザのタブを通してアプリを操作します。実験のあいだは、**このタブを開いたまま**にしてください。
> スマホで試すときは、画面を消したり、ほかのアプリに切り替えたりすると止まることがあります。

---

## A. Claude（claude.ai・Claude のデスクトップ／スマホアプリ）

1. Claude の「設定」→「コネクタ」を開く
2. 「カスタムコネクタを追加」を押す
3. 次のように入れる
   - 名前：`Whiteboard Animation Maker`
   - URL：`<URL>`
   - 認証：なし（OAuth の設定は空のまま）
4. 追加したら、新しいチャットを開き、入力欄の「＋」（ツール）から、このコネクタがオンになっているかを確かめる

※ チームや会社のプランでは、管理者しかカスタムコネクタを追加できないことがあります。

## B. Claude Code（ターミナル）

```bash
claude mcp add --transport http whiteboard <URL>
```

- つながったかの確認：`claude mcp list`（`whiteboard` が「connected」になっていれば OK）
- 消すとき：`claude mcp remove whiteboard`

## C. Codex（CLI・IDE 拡張）

`~/.codex/config.toml`（Windows は `C:\Users\<ユーザー名>\.codex\config.toml`）に、次を追加します。

```toml
[mcp_servers.whiteboard]
url = "<URL>"
```

- Codex を開き直してから使います
- つながらないときは、Codex のバージョンによって HTTP の MCP を使う設定が別に必要なことがあります。Codex の説明書の「MCP」の項目（`url` を使う「Streamable HTTP」のサーバー）を確かめてください

---

## つながったかを確かめる指示文（A・B・C 共通）

AI に、次をそのまま送ります。

```text
「whiteboard」（Whiteboard Animation Maker）の MCP ツールを使って、get_status を1回だけ呼び、
返ってきた内容（作品名・ページ数・画像の有無・グループ数）を日本語で短く教えてください。
ほかの操作はしないでください。
```

- うまくいくと、AI が作品名などを答え、アプリの「AI 連携（MCP）」の画面に「AI の操作 1 回」と出ます（画像の読み込みや並べ替えなど、作品を変える操作のときは、アプリの画面に「AI：…」と短い知らせも出ます）
- **「アプリが開いていません」と返ってきたとき**：ステップ 0 のタブが閉じているか、受け付けがオフです。タブを開いて、オンにしてください
- **ツールが見つからないと言われたとき**：コネクタ（MCP サーバー）の登録を見直してください。Claude は新しいチャットで、Codex は開き直してから試します
- **タブを開いているのに「アプリが開いていません」と返るとき**：合言葉を作り直した後の古い URL を登録している可能性があります。アプリで今の URL をコピーし直して、登録し直してください
- **404 が返るとき**：URL の写し間違い（途中で切れている など）です
- **403（エラー 1010）が返るとき**：Cloudflare が、そのつなぎ方を機械的なアクセスとして弾いています。どの AI・どのつなぎ方で起きたかを控えておいてください

## 実験が終わったら

- アプリの「AI からの接続を受け付ける」をオフにする
- 不安なときは「合言葉を作り直す」で、今の URL を使えなくできる（AI 側の登録も新しい URL にし直す）
