# 1. ダミーのホワイトボード画像を作る

AI 連携の実験に使う、ホワイトボードの清書画像を作ります。
やり方は2つあります。使う AI に合わせて、どちらか一方の指示文をそのまま貼り付けてください。

- **A. 画像を作れる AI**（ChatGPT の画像生成、Gemini など）に頼む
- **B. Codex・Claude Code**（ファイルを作れる AI）に、プログラムで描いてもらう

どちらでも、できた画像は **PNG（またはJPEG）** で保存します。
アプリは SVG を絵として読み込めないので、SVG のときは PNG に変換してもらってください。

---

## A. 画像を作れる AI に貼る指示文

```text
ホワイトボードに手描きで清書したような説明図の画像を、1枚作ってください。
「描いていく動画」を作るアプリの素材にするので、次の条件を必ず守ってください。

【大きさ・背景】
- 横長 3:2（例：1536×1024px）
- 背景は真っ白の無地（ホワイトボードの枠・影・反射・木目・質感は入れない）

【描き方】
- 黒・青・赤・緑のマーカーで描いたような、はっきりした線だけで描く
- 線は太め（細い線や、かすれ・にじみ・グラデーション・写真・立体的な陰影は使わない）
- 塗りつぶしは少しだけ。使うときは、線と同じマーカーで塗った平らな色にする
- 文字と絵が重ならないよう、まわりに十分な余白をとる

【内容】
- 上の中央に、大きな日本語のタイトル：「朝のルーティン」
- その下に、左から右へ3つの区切り（番号つき）を並べる
  1. 「起きる」＋目覚まし時計の簡単な絵
  2. 「顔を洗う」＋蛇口と水しぶきの簡単な絵
  3. 「朝ごはん」＋お皿とトーストの簡単な絵
- 区切りのあいだを、右向きの矢印でつなぐ
- いちばん下に、小さめの文字で「今日もいい一日を！」

【文字】
- 日本語は、正しい字形の、読みやすい手書き風の文字にする（崩れた字・存在しない字は使わない）
- 文字の数は上に書いたものだけにする（英語や余計な文字を足さない）
```

---

## B. Codex・Claude Code に貼る指示文

```text
動画アプリの実験用に、ホワイトボードの清書画像（PNG）を1枚、プログラムで作ってください。

【出力】
- ファイル：./whiteboard-test.png（このフォルダに保存）
- 大きさ：1536×1024px、背景は真っ白（#ffffff）の無地

【作り方】
- Python の Pillow（なければ pip install pillow）で描く。ほかの方法でもよいが、最後は PNG にする
- 日本語の文字には、日本語が入ったフォントを使う
  - Windows：C:/Windows/Fonts/YuGothB.ttc または meiryob.ttc
  - Mac：/System/Library/Fonts/ヒラギノ角ゴシック W6.ttc
  - 見つからないときは、使えるフォントを探してから描く（文字化け・豆腐［□］になっていないか必ず確かめる）
- 線はすべて太め（6〜12px）、角は丸く。色は黒 #222、青 #1f6feb、赤 #e5484d、緑 #2f9e44 の4色だけ
- グラデーション・影・写真は使わない

【内容】
- 上の中央に、大きなタイトル「朝のルーティン」（文字の高さ 120px くらい、黒）
- その下に、左から右へ3つの区切りを並べる。それぞれ、丸囲みの番号（1・2・3）、見出しの文字、簡単な絵
  1. 「起きる」：目覚まし時計（丸い本体・2本の針・上に2つのベル）
  2. 「顔を洗う」：蛇口と、しずく3つ
  3. 「朝ごはん」：楕円のお皿と、角を丸めた四角いトースト
- 区切りのあいだに、右向きの矢印（青）
- いちばん下の中央に、少し小さめの文字「今日もいい一日を！」（赤）
- 文字と絵が重ならないよう、余白をしっかりとる

【確かめること】
- できた画像を自分で開いて（または縮小して見て）、文字が正しく出ていること、はみ出しや重なりがないことを確かめてから終わる
- 最後に、保存したファイルの場所を教えてください
```

---

## うまくいかないとき

- **文字がおかしい（崩れる・存在しない字になる）**：A の画像生成ではよく起きます。B のやり方（フォントで描く）にすると確実です。
- **線が細い・薄い**：アプリの自動の描き順づくりが、文字や絵をうまく見分けられません。「線をもっと太く、濃く」と頼み直してください。
- **背景にホワイトボードの質感や影が入る**：「背景は真っ白の無地。質感・影は入れない」ともう一度伝えてください。
