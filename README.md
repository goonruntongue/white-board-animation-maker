# white-board-animation-maker

ホワイトボードの清書画像から、**ペンを持つ手が描いていくように見えるアニメーション**を作るデスクトップアプリです。
仕様は [PRD/whiteboard-animation-app-spec.md](PRD/whiteboard-animation-app-spec.md) を参照してください。

## 使い方

1. 清書画像（PNG / JPEG / WebP）をウィンドウへドラッグ＆ドロップ（または `Ctrl+I`）
2. **「自動」で描き順の下書きを作る**（ツールバーの ✦ ／ 描き順パネルの「自動で作る」）。画像の文字・図・枠をかたまりごとに見つけ、枠 → 中身の順に、手が書いていくグループを作ります。描き方は次の4つです。
   - **自然に描く**（既定）：文字の大きさから行・まとまりを見分け、近いまとまり（パネル・段組みの列）を書き切ってから次へ。行は1回で左→右、背の高い図は左の列から上→下、雲形・丸・四角の枠は輪郭に沿って一周
   - **かたまりを描く**：従来の方式。**手の動き**（なめらか／上下にごしごし／左右にごしごし／斜めにごしごし。上下・左右それぞれの強さを 0〜100% で調整・抑制でき、前回の設定を覚えます）を選べる
   - **選択範囲を塗る**：「範囲全体を塗る」（方向・ごしごし・ペンの太さを指定して均一に）か「中の文字・図を見分けて描く」（範囲の中だけを自然に描くと同じ順番で）
   
   かたまりの大きさ（細かく／ふつう／大きく）と書く速さも選べます。できたグループは、順番の入れ替え・録り直し・描き足し・消しゴムで直せます
   - 手でなぞる場合は、「手描き」の「ブラシ」（`D`）で、何も選ばずに描かせたい順に画像の上をなぞる（1本ごとに新しいグループになる。「同一グループ」をオンにしている間に描いた線は1つのグループにまとまり、オンにし直すと次のグループになる。太さは細〜特大のプリセットかスライダー。スマホはブラシに切り替えるとタイムラインが隠れ、絵と下のパネルの境目の山形の取っ手でどの操作中でも出し入れできる。隠しているときは絵の左下の再生ボタンで確かめられる。上のオプションバーは右上の ⚙ で2段／1段を切り替えられる）
   - 自動で作ったグループを直すときは「手描き」（`W`）：絵の上をタップして線（一筆）を選び、太さを変える・ドラッグで動かす・拡大縮小する・**ブラシ**（線を選んでから足りない所をなぞると、そのグループに線が足され表示範囲も広がる）・**消しゴム**で削る（選んでいる線にだけ効き、同じグループのほかの線には効かない）・**パス編集**（選んでいる線だけを、アンカーとハンドルの曲線として直す。ほかの線を押しても選び替わらない。ダブルクリックでアンカー追加、`Delete` で削除、`Alt`＋ドラッグで角。絵の上に浮かぶ道具パネルで Illustrator と同じ **パス選択**（`A`）・**アンカーポイントの切り替え**（`Shift`+`C`）・**アンカーポイントの追加・削除**（`+` / `-`）を切り替えられる）。選んだ線を描き終えた瞬間の見え方がその場で変わる。線のまとまりがグループで、グループでは順番・再生時間・待ち時間・表示だけを決める
   - 「選ぶ・動かす」の「自動選択」チェックを外すと、いま選んでいる線から選び替わらず、どこをドラッグしてもその線が動きます。線を選んでいるときのブラシは「描き直す」が既定で、一筆なぞるとその線が置き換わります。ブラシの横の ▼ で「線を追加」（グループの最後に足す）に切り替えられ、選んだ方は覚えておきます（スマホではブラシと描き直しのあいだ、タイムラインが隠れて絵を広く使えます）。「選択した線を削除」はその線だけを消し（線が1本だけならグループごと。確認あり）、「ここで分ける」は選んだ線の手前でグループを2つに分けます（結合の取り消しにも）。「自動で再作成」は表示範囲のあるグループを対象に、その範囲を解析して元の順番の位置に置き換えます。ほかのグループは変更せず、元に戻すで取り消せます。
   - なぞった範囲がくっきり、まだの範囲は薄く表示されるので、描き漏れがひと目で分かります
   - 大きいペン先でラフになぞると、隣の文字まで出てしまうことがあります。先に **選択範囲**（長方形・楕円形・投げ縄）を作ってからなぞると、範囲の外はマスクが外れません。
     範囲は自動にも手描きにも効く共通の指定なので、ツールバーではなく絵の右下の「範囲」（PC は形の3つのボタン）から作ります。囲み終えたらオプションバーの「完了」（または Enter）で前の道具に戻ります。
     範囲の道具のときはオプションバーに合成モード（新規・追加・除外・交差）が出ます。Shift で追加、Alt で除外、Shift+Alt で交差も可。投げ縄はドラッグで自由形、クリックで多角形（Enter / ダブルクリックで確定）。
     選択範囲は描いたグループごとに保存されるので、再生や書き出したHTMLでも範囲の外は表示されません。
   - 描き漏れに気づいたら、「手描き」でグループを選び「ブラシ」でなぞると、そのグループに線を足せます。新しいグループは作らず、再生では手がペンを上げて移動し、続きを描きます（つなぎ目は表示されません）。描き足す部分だけペン先の太さを変えることもできます。
   - なぞった後にはみ出しに気づいたら、**消しゴム**（`E`）で、選んでいるグループの表示をなぞって消せます。道筋と時間はそのままなので、手の動きや再生時間は変わりません。消した跡は右パネルで「すべて戻す」こともできます。範囲ツールで範囲を作って `Delete`（スマホは「中を消す」）を押すと、範囲の中をまとめて消せます。
3. 左パネルで描き順の並び替え・録り直し・削除、右パネルで幅・速度・待機時間を調整
4. `Space` で再生して確認
5. 「HTMLを書き出す」（`Ctrl+E`）で、オフライン再生できる単一HTMLを保存
   - **複数ページ**：画像を追加で読み込む（または複数まとめてドロップする）と、ページが増えます。左パネル上のページ一覧で切り替え・並べ替え・複製・削除（長押し／右クリック）。書き出すと、クリックや矢印キーでページ送りできる **HTMLスライド** になります
   - 再生の始め方（すぐ／クリックで／画面に見えたら）、ページの進め方、まわりの背景（暗い・白・透過）、マーカーの書く音を選べます
   - スライドへの埋め込み：`<iframe>` で読み込み、`postMessage({ source: 'wb', cmd: 'play' })` などで外から操作できます（書き出し画面の「スライドに埋め込むには」を参照）
   - 動画が必要なら「動画」（`Ctrl+Shift+E`）で **MP4** を書き出し。1コマずつ圧縮する高速方式で、再生時間を待たずに仕上がります（約1分の動画が数秒）。対応していない端末では、画面を録画する方式（WebM / MP4）に切り替えられます。全ページがつながった1本の動画になります

作業内容は `.wbanim` プロジェクトファイルとして保存できます（`Ctrl+S`）。

未保存の変更は、約2分おきに端末内へ自動でバックアップされます（最大20件・約40分ぶん）。フリーズや強制終了で正しく終了しなかった場合は、次の起動時に「自動バックアップから復元」が開き、何分前の状態に戻すかを選べます（ツールバーの時計アイコン／メニューからも開けます）。

画面は工業製品／オーディオ機器風のデザインで、ツールバー右のスイッチでライト／ダークを切り替えられます（メニューの「表示 → テーマ」では「システム設定に合わせる」も選べます）。

## はじめての方へ（ツアーガイド）

起動すると、画面のボタンのそばに順番に説明が出る **ツアーガイド** が表示されます（画像の読み込み → 自動 → 描く → 描き順 → 再生 → 書き出し）。

- 途中で「スキップ」できます。「次回から表示しない」にチェックすると、次の起動から出ません
- ツアー・使い方ガイド（説明カード）・サンプル画像は、右上の小さな ⚙ ボタンにまとめています。「起動時にツアーを表示」もここで切り替えられます（デスクトップ版はメニューの「ヘルプ」からも開けます）
- PC の上のバーは、画面の幅に入りきらないときは道具とオプションの部分だけ横にスクロールします（端の矢印・ホイールでも送れます）。右端の保存・書き出しはいつも見えます
- 自動で作ったあとは「選ぶ・動かす」に切り替わり、タイムラインが出ます（そのまま再生して確かめ、線を選んで直せます）。スマホでは、選んだグループの線の番号をタイムラインの操作と同じ1行に並べ、絵を広く使えるようにしています
- ボタンの説明：PC はボタンにマウスを少し乗せると、名前・説明・ショートカットが小さく出ます。スマホはボタンを**長押し**すると画面下に説明が出ます（そのときボタンは働きません。ふつうに押せばすぐ働きます）。説明は `src/renderer/src/lib/hints.ts` にまとめています
- Electron 版・Web（PWA）版・スタンドアロン版で同じように動きます。設定はそれぞれの保存領域に記録されます

## スマホ・タブレット（PWA 版）

PC は Electron 版、スマホ・タブレットはブラウザで開いて「ホーム画面に追加」する PWA 版を使います（同じコードから作ります）。

スマホでは画面の作りを変えて、縦長の画面と指での操作に合わせています（タブレットとPCは従来の画面）。

- **親指で届く下のドック**：作業の順番どおり 自動／手描き ・ 描き順／設定／書き出し（「手描き」でグループを選ぶ・消す操作もここにまとめた）
- **オプションバー**：選んだ道具の設定だけを表示（ペン先サイズ、範囲の合成モード、直すときの操作と、選んだグループの描き順の入れ替え・削除。ブラシの ▼ で「描き直す／線を追加」）
- **ルーペ**：指でなぞると指先が隠れるので、指の上に2倍強の拡大表示を出す
- **2本指**でピンチ＝拡大縮小・移動（1本目で描き始めた線は取り消される）
- **範囲**は自動にも手描きにも効く共通の指定なので、ドックではなく絵の右下の「範囲」ボタンから。もう一度押すと形を選べ、オプションバーの「完了」で前の道具に戻る。投げ縄の多角形は「確定／1つ戻る／取消」ボタンで操作
- **長押しメニュー**：タイムラインのアイテムや描き順の行を長押しすると、ここから再生・詳しく編集・録り直す・前後へ移動・複製・前／次のグループと結合・再生から外す・削除（PC では右クリック）。結合しても描くタイミングは変わりません
- **描き順・設定**は下から出るシート（つまみを下へスワイプで閉じる）。描き順の並べ替えは選んだ行の ↑↓
- **横向き**ではドックが左の縦レールになり、キャンバスを広く使える
- **写真を撮る**：カメラで撮影した画像をそのまま読み込める
- 保存・書き出しは共有シートから。動画は WebM、録画できない端末（iPhone など）では MP4
- 一度開けばオフラインでも起動できる（フォントと手素材は使った分から保存）

アプリアイコンを差し替えたら `npm run icons:pwa` で PWA 用アイコンを作り直せます（Pillow が必要）。

```bash
npm run build:web
```

`dist/web/` を HTTPS のサーバーに置くと、スマホから開いてホーム画面に追加できます（PWA は HTTPS が必要。localhost は例外）。

### 紹介サイトとアプリを一緒に公開する

`main` に push すると、GitHub Actions（`.github/workflows/deploy-site.yml`）が下と同じ手順で自動的に公開します（Cloudflare の API トークンをリポジトリの Secrets の `CLOUDFLARE_API_TOKEN` に登録しておく必要があります）。手元から公開するときの手順は次のとおりです。

Cloudflare Pages のルートには `site/` の紹介サイト、`/app/` には `dist/web/` のブラウザ版を配置します。`site/` だけを公開するとアプリは準備中のページに戻るため、両方をまとめてからデプロイしてください。PowerShell での例：

```powershell
npm run build:web
if ($LASTEXITCODE -ne 0) { throw 'Web版のビルドに失敗しました' }
$publishDir = Join-Path $env:TEMP ('whiteboard-site-' + [guid]::NewGuid())
New-Item -ItemType Directory -Path $publishDir | Out-Null
Copy-Item site/* $publishDir -Recurse -Force
Copy-Item dist/web/* (Join-Path $publishDir 'app') -Recurse -Force
npx.cmd wrangler pages deploy $publishDir --project-name whiteboard-animation-maker --branch main
```

紹介サイトの `noindex` ヘッダーはアプリにも適用されます。現在ブラウザ版にログインは必要ありません。
手元で確認するときは `npm run preview:web`（http://localhost:4310 ）。

```

├─ main/            Electron メインプロセス（ウィンドウ・メニュー・ファイルダイアログ）

   ├─ engine/

   │  ├─ types.ts       プロジェクトデータの型（.wbanim の中身）
   │  ├─ project.ts     プロジェクト生成・保存形式・グループの録画処理
   │  └─ handAsset.ts   内蔵の手・ペン素材（SVG、仮素材）

   └─ commands.ts       メニュー・ショートカット共通の操作
```

### 描画の仕組み（PRD 6章）

- **マスク層**: なぞったグループを時間に沿って太い線で描き足していく
- **画像層**: 完成画像をマスクで切り抜く（`destination-in`）→ 描いた所だけ見える
- **手の層**: 現在のペン先位置に手素材を重ね、進行方向に合わせてわずかに傾ける

`renderAt(ms)` は任意の時刻へシークでき、巻き戻し時はマスクを作り直します。
グループは、なぞったときの時刻 `t` を保存しているので、手書きらしい速度の緩急を再現できます。

## AI 連携（MCP）

デスクトップ版は、MCP（Model Context Protocol）のエンドポイントを持ちます。Claude Code・Codex などの MCP クライアントから、画像の読み込み・描き順の自動作成・グループの並べ替えや描き直し・1コマの確認・書き出し（.wbanim / MP4 / WebM / GIF / HTML）までを操作できます。

- 歯車のメニュー →「AI 連携（MCP）」で受け付けをオンにし、表示される URL（`http://127.0.0.1:39271/mcp/<合言葉>`）を MCP サーバー（Streamable HTTP）として登録する
- 例：`claude mcp add --transport http whiteboard http://127.0.0.1:39271/mcp/<合言葉>`
- 道具の一覧と説明は `src/shared/mcp.ts`、実際の操作は `src/renderer/src/automation.ts`、待ち受けは `src/main/mcpServer.ts`
- 書き出したファイルは「書類」の `Whiteboard Animation Maker/AI exports` に保存する
- Web 版（Cloudflare の中継経由）は準備中
