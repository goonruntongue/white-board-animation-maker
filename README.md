# white-board-animation-maker

ホワイトボードの清書画像から、**ペンを持つ手が描いていくように見えるアニメーション**を作るデスクトップアプリです。
仕様は [PRD/whiteboard-animation-app-spec.md](PRD/whiteboard-animation-app-spec.md) を参照してください。

## 使い方

1. 清書画像（PNG / JPEG / WebP）をウィンドウへドラッグ＆ドロップ（または `Ctrl+I`）
2. **「自動」で描き順の下書きを作る**（ツールバーの ✦ ／ 描き順パネルの「自動で作る」）。画像の文字・図・枠をかたまりごとに見つけ、枠 → 中身の順に、手が左から右へ書いていく軌跡を作ります。かたまりの大きさ（細かく／ふつう／大きく）、書く速さ、**手の動き**（なめらか／上下にごしごし／左右にごしごし／斜めにごしごし。上下・左右それぞれの強さを 0〜100% で調整・抑制でき、前回の設定を覚えます）を選べます。できた軌跡は、順番の入れ替え・録り直し・描き足し・消しゴムで直せます
   - 手でなぞる場合は、「描く」ツール（`D`）で描かせたい順に画像の上をなぞる
   - なぞった範囲がくっきり、まだの範囲は薄く表示されるので、描き漏れがひと目で分かります
   - 大きいペン先でラフになぞると、隣の文字まで出てしまうことがあります。先に **選択範囲**（長方形・楕円形・投げ縄）を作ってからなぞると、範囲の外はマスクが外れません。
     選択ツールのときはツールバーに合成モード（新規・追加・除外・交差）が出ます。Shift で追加、Alt で除外、Shift+Alt で交差も可。投げ縄はドラッグで自由形、クリックで多角形（Enter / ダブルクリックで確定）。
     選択範囲は描いた軌跡ごとに保存されるので、再生や書き出したHTMLでも範囲の外は表示されません。
   - 描き漏れに気づいたら、軌跡を選んで **Shift＋ドラッグ**（またはツールバー／スマホのオプションバーの「描き足す」をオン）で、その軌跡に描き足せます。新しい軌跡は作らず、再生では手がペンを上げて移動し、続きを描きます（つなぎ目は表示されません）。描き足す部分だけペン先の太さを変えることもできます。
   - なぞった後にはみ出しに気づいたら、**消しゴム**（`E`）で、選んでいる軌跡の表示をなぞって消せます。道筋と時間はそのままなので、手の動きや再生時間は変わりません。消した跡は右パネルで「すべて戻す」こともできます。
3. 左パネルで描き順の並び替え・録り直し・削除、右パネルで幅・速度・待機時間を調整
4. `Space` で再生して確認
5. 「HTMLを書き出す」（`Ctrl+E`）で、オフライン再生できる単一HTMLを保存
   - **複数ページ**：画像を追加で読み込む（または複数まとめてドロップする）と、ページが増えます。左パネル上のページ一覧で切り替え・並べ替え・複製・削除（長押し／右クリック）。書き出すと、クリックや矢印キーでページ送りできる **HTMLスライド** になります
   - 再生の始め方（すぐ／クリックで／画面に見えたら）、ページの進め方、まわりの背景（暗い・白・透過）、マーカーの書く音を選べます
   - スライドへの埋め込み：`<iframe>` で読み込み、`postMessage({ source: 'wb', cmd: 'play' })` などで外から操作できます（書き出し画面の「スライドに埋め込むには」を参照）
   - 動画が必要なら「動画」（`Ctrl+Shift+E`）で **MP4** を書き出し。1コマずつ圧縮する高速方式で、再生時間を待たずに仕上がります（約1分の動画が数秒）。対応していない端末では、画面を録画する方式（WebM / MP4）に切り替えられます。全ページがつながった1本の動画になります

作業内容は `.wbanim` プロジェクトファイルとして保存できます（`Ctrl+S`）。

未保存の変更は、約2分おきに端末内へ自動でバックアップされます（最大20件・約40分ぶん）。フリーズや強制終了で正しく終了しなかった場合は、次の起動時に「自動バックアップから復元」が開き、何分前の状態に戻すかを選べます（ツールバーの時計アイコン／メニューからも開けます）。

画面は工業製品／オーディオ機器風のデザインで、ツールバー右のスイッチでライト／ダークを切り替えられます（メニューの「表示 → テーマ」では「システム設定に合わせる」も選べます）。

## はじめての方へ（ツアーガイド）

起動すると、画面のボタンのそばに順番に説明が出る **ツアーガイド** が表示されます（画像の読み込み → 自動 → 描く → 描き順 → 再生 → 書き出し）。

- 途中で「スキップ」できます。「次回から表示しない」にチェックすると、次の起動から出ません
- ツアー・使い方ガイド（説明カード）・サンプル画像は、右上の小さな ⚙ ボタンにまとめています。「起動時にツアーを表示」もここで切り替えられます（デスクトップ版はメニューの「ヘルプ」からも開けます）
- Electron 版・Web（PWA）版・スタンドアロン版で同じように動きます。設定はそれぞれの保存領域に記録されます

## スマホ・タブレット（PWA 版）

PC は Electron 版、スマホ・タブレットはブラウザで開いて「ホーム画面に追加」する PWA 版を使います（同じコードから作ります）。

スマホでは画面の作りを変えて、縦長の画面と指での操作に合わせています（タブレットとPCは従来の画面）。

- **親指で届く下のドック**：描く／範囲／選ぶ ・ 描き順／設定／書き出し
- **オプションバー**：選んだ道具の設定だけを表示（ペン先サイズ、範囲の合成モード、選んだ軌跡の前後・録り直し・削除）
- **ルーペ**：指でなぞると指先が隠れるので、指の上に2倍強の拡大表示を出す
- **2本指**でピンチ＝拡大縮小・移動（1本目で描き始めた線は取り消される）
- **範囲の形**はドックの「範囲」をもう一度押して選ぶ。投げ縄の多角形は「確定／1つ戻る／取消」ボタンで操作
- **長押しメニュー**：タイムラインのアイテムや描き順の行を長押しすると、ここから再生・詳しく編集・録り直す・前後へ移動・複製・再生から外す・削除（PC では右クリック）
- **描き順・設定**は下から出るシート（つまみを下へスワイプで閉じる）。描き順の並べ替えは選んだ行の ↑↓
- **横向き**ではドックが左の縦レールになり、キャンバスを広く使える
- **写真を撮る**：カメラで撮影した画像をそのまま読み込める
- 保存・書き出しは共有シートから。動画は WebM、録画できない端末（iPhone など）では MP4
- 一度開けばオフラインでも起動できる（フォントと手素材は使った分から保存）

アプリアイコンを差し替えたら `npm run icons:pwa` で PWA 用アイコンを作り直せます（Pillow が必要）。

```bash
npm run build:web
```

`dist/web/` を HTTPS のサーバーに置くと、スマホから開いてホーム画面に追加できます（PWA は HTTPS が必要。localhost は例外）。
手元で確認するときは `npm run preview:web`（http://localhost:4310 ）。

## 開発

必要なもの: Node.js 22 以上

```bash
npm install
```

npm 11 の設定によっては Electron 本体のダウンロード（install スクリプト）がスキップされます。
`npm run dev` で「Electron failed to install correctly」と出た場合は次を実行してください。

```bash
node node_modules/electron/install.js
```

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | Electron 版を開発モードで起動（ホットリロード） |
| `npm run dev:web` | ブラウザ版（PWA 版）を開発モードで起動（http://localhost:5310 ） |
| `npm run build:standalone` | アプリ全体を1つのHTMLファイルにまとめたスタンドアロン版を `dist/standalone/index.html` に作る |
| `npm run build:web` / `npm run preview:web` | PWA 版を `dist/web/` にビルド / ビルド結果を確認 |
| `npm run typecheck` | TypeScript の型チェック |
| `npm run build` | `out/` にビルド |
| `npm run dist:win` | Windows インストーラーを `release/` に作成 |

## 構成

```
src/
├─ main/            Electron メインプロセス（ウィンドウ・メニュー・ファイルダイアログ）
├─ preload/         レンダラーへ公開する安全なAPI（window.desktop）
└─ renderer/src/
   ├─ engine/
   │  ├─ wb-engine.js   描画エンジン本体。エディタと書き出したHTMLの両方で同じコードが動く
   │  ├─ types.ts       プロジェクトデータの型（.wbanim の中身）
   │  ├─ project.ts     プロジェクト生成・保存形式・軌跡の録画処理
   │  └─ handAsset.ts   内蔵の手・ペン素材（SVG、仮素材）
   ├─ export/           単一HTML / WebM 書き出し
   ├─ components/       画面部品（ステージ・描き順リスト・インスペクタ・タイムライン など）
   ├─ lib/platform.ts   ファイル入出力（Electron ではOSダイアログ、ブラウザ版ではダウンロード）
   ├─ store.ts          状態管理（zustand・元に戻す/やり直す）
   └─ commands.ts       メニュー・ショートカット共通の操作
```

### 描画の仕組み（PRD 6章）

- **マスク層**: なぞった軌跡を時間に沿って太い線で描き足していく
- **画像層**: 完成画像をマスクで切り抜く（`destination-in`）→ 描いた所だけ見える
- **手の層**: 現在のペン先位置に手素材を重ね、進行方向に合わせてわずかに傾ける

`renderAt(ms)` は任意の時刻へシークでき、巻き戻し時はマスクを作り直します。
軌跡は、なぞったときの時刻 `t` を保存しているので、手書きらしい速度の緩急を再現できます。
