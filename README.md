# white-board-animation-maker

ホワイトボードの清書画像から、**ペンを持つ手が描いていくように見えるアニメーション**を作るデスクトップアプリです。
仕様は [PRD/whiteboard-animation-app-spec.md](PRD/whiteboard-animation-app-spec.md) を参照してください。

## 使い方

1. 清書画像（PNG / JPEG / WebP）をウィンドウへドラッグ＆ドロップ（または `Ctrl+I`）
2. 「描く」ツール（`D`）で、描かせたい順に画像の上をなぞる
   - なぞった範囲がくっきり、まだの範囲は薄く表示されるので、描き漏れがひと目で分かります
3. 左パネルで描き順の並び替え・録り直し・削除、右パネルで幅・速度・待機時間を調整
4. `Space` で再生して確認
5. 「HTMLを書き出す」（`Ctrl+E`）で、オフライン再生できる単一HTMLを保存
   - 動画が必要なら「動画」（`Ctrl+Shift+E`）で WebM を書き出し

作業内容は `.wbanim` プロジェクトファイルとして保存できます（`Ctrl+S`）。

### ショートカット

| キー | 操作 |
| --- | --- |
| `D` / `V` / `H` | 描く / 選択 / 移動 ツール |
| `Space` / `Home` | 再生・一時停止 / 先頭へ |
| `Tab` | 編集表示 ⇔ プレビュー表示 |
| `[` / `]` | 新しい軌跡の幅を細く / 太く |
| `↑` / `↓` | 前 / 次の軌跡を選択 |
| `Delete` | 選択中の軌跡を削除 |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す / やり直す |
| ホイール / `Alt`+ドラッグ / 中ボタンドラッグ | ズーム / 表示移動 |

## 開発

必要なもの: Node.js 22 以上

```bash
npm install
```

npm 11 の設定によっては Electron 本体のダウンロード（install スクリプト）がスキップされます。
`npm run dev` で「Electron failed to install correctly」と出た場合は次を実行してください。

```bash
node node_modules/electron/install.js
```

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | Electron 版を開発モードで起動（ホットリロード） |
| `npm run dev:web` | ブラウザ版を起動（PRD フェーズ1 の検証用。http://localhost:5173 ） |
| `npm run typecheck` | TypeScript の型チェック |
| `npm run build` | `out/` にビルド |
| `npm run dist:win` | Windows インストーラーを `release/` に作成 |

## 構成

```
src/
├─ main/            Electron メインプロセス（ウィンドウ・メニュー・ファイルダイアログ）
├─ preload/         レンダラーへ公開する安全なAPI（window.desktop）
└─ renderer/src/
   ├─ engine/
   │  ├─ wb-engine.js   描画エンジン本体。エディタと書き出したHTMLの両方で同じコードが動く
   │  ├─ types.ts       プロジェクトデータの型（.wbanim の中身）
   │  ├─ project.ts     プロジェクト生成・保存形式・軌跡の録画処理
   │  └─ handAsset.ts   内蔵の手・ペン素材（SVG、仮素材）
   ├─ export/           単一HTML / WebM 書き出し
   ├─ components/       画面部品（ステージ・描き順リスト・インスペクタ・タイムライン など）
   ├─ lib/platform.ts   ファイル入出力（Electron ではOSダイアログ、ブラウザ版ではダウンロード）
   ├─ store.ts          状態管理（zustand・元に戻す/やり直す）
   └─ commands.ts       メニュー・ショートカット共通の操作
```

### 描画の仕組み（PRD 6章）

- **マスク層**: なぞった軌跡を時間に沿って太い線で描き足していく
- **画像層**: 完成画像をマスクで切り抜く（`destination-in`）→ 描いた所だけ見える
- **手の層**: 現在のペン先位置に手素材を重ね、進行方向に合わせてわずかに傾ける

`renderAt(ms)` は任意の時刻へシークでき、巻き戻し時はマスクを作り直します。
軌跡は、なぞったときの時刻 `t` を保存しているので、手書きらしい速度の緩急を再現できます。
